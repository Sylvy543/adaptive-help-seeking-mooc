Online Resource 2 — Independent Coder Ratings
Online Resource 2 — 独立编码者原始评分

1. Contents and provenance 文件内容与来源

Coding_Sheet_Coder1.xlsx contains Coder 1's original independent classifications. Coding_Sheet_Coder2.xlsx contains Coder 2's original independent classifications. Both workbooks are retained unchanged from the round-1 Online Resource 2 files. The original instructions, feature descriptions, sample inputs, classification entries, and notes are preserved. This README is an explanatory addition for the present revision; it is not part of the instructions used during independent coding.

Coding_Sheet_Coder1.xlsx包含编码者1的原始独立分类；Coding_Sheet_Coder2.xlsx包含编码者2的原始独立分类。两份工作簿均与第一轮Online Resource 2中的文件保持一致，原有说明、功能描述、样例输入、分类条目和备注均保留。本README是本轮修订新增的解释性说明，不属于独立编码时使用的指导材料。

2. Reading the worksheets 如何阅读工作表

Each workbook contains three worksheets: Instructions, Coding Sheet, and Quick Reference. In Coding Sheet, rows 3–18 contain the 16 features. Columns B and C provide the Chinese feature names and English glosses, columns D and E provide interaction frequencies and percentages, columns F and G provide the descriptions and sample inputs supplied for coding, and column H contains the coder's independent classification. Column I is reserved for the coder's notes; blank notes are preserved as blank and are not evidence that a rationale was recorded. The five available classifications are Task (FT), Process (FP), Self-Regulation (FR), Self (FS), and Other / Not Applicable.

每份工作簿包含Instructions、Coding Sheet和Quick Reference三个工作表。Coding Sheet的第3–18行对应16项功能；B、C列为中文功能名及英文释义；D、E列为交互频数及百分比；F、G列为编码时提供的功能描述与样例输入；H列为该编码者的独立分类。I列用于记录编码者备注；空白备注保持为空，不能据此声称记录了某项编码理由。可选类别共五类：Task (FT)、Process (FP)、Self-Regulation (FR)、Self (FS)和Other / Not Applicable。

3. Frequency denominator and unit of agreement 频数口径与一致性分析单位

The frequency column sums to 108,351 interactions in each workbook, and the percentages use 108,351 as their denominator. These are full-dataset descriptive frequencies presented with the coding materials. They are not the main-sample frequencies for the 16,389 users with 85,815 AI interactions. Main-sample feature counts are provided separately in Online Resource 1, Appendix A.6. The agreement analysis treats each feature as one item, giving 16 paired classifications; it does not weight the ratings by interaction frequency. Raw inter-coder agreement is 13/16 (81.25%), with Cohen's κ = .716.

每份工作簿的频数列合计108,351次交互，百分比也以108,351为分母。这些是随编码材料提供的完整数据集描述性频数，并非16,389名用户、85,815次AI交互的主分析样本频数。主分析功能频数另见Online Resource 1附录A.6。一致性分析以每项功能为一个条目，共16对分类，不按交互频数加权。原始编码者间一致数为13/16（81.25%），Cohen's κ = .716。

4. Raw ratings, adjudication, and author mappings 原始评分、裁决与作者映射

The following three items have different raw classifications between the coders. The adjudicated categories are recorded separately here for interpretation; they have not been written back into either coder's workbook.

以下三项功能的原始分类存在分歧。裁决类别在此单独说明，便于解释，未回填到任何一位编码者的原始工作簿中。

From Turing Bot (General Chatbot): Coder 1 = Self-Regulation; Coder 2 = Self; adjudicated category = Self.
From Aminer (Academic Search): Coder 1 = Task; Coder 2 = Process; adjudicated category = Process.
TA Answer Browser: Coder 1 = Other / Not Applicable; Coder 2 = Task; adjudicated category = Other / Not Applicable.

From Turing Bot（通用聊天机器人）：编码者1为Self-Regulation，编码者2为Self，裁决为Self。
From Aminer（学术搜索）：编码者1为Task，编码者2为Process，裁决为Process。
TA Answer Browser（助教回答浏览）：编码者1为Other / Not Applicable，编码者2为Task，裁决为Other / Not Applicable。

The coder-anchored sensitivity analysis uses the original agreements together with these three adjudications, without subsequent author remapping. The primary analyses instead retain the historical author mapping. These schemes are different: for example, both coders classified From MOOCCube as Task and Pop-up Reflection Question as Process, while the historical author mapping assigns them to Process and Self-Regulation, respectively; TA Answer Browser was adjudicated to Other but was assigned to Self-Regulation in the historical pipeline. These differences must not be resolved by changing the raw ratings in the workbooks. The full mapping, including other author decisions, is documented in Online Resource 1, Appendix A.6.

编码者锚定敏感性分析采用原始编码共识及上述三项裁决，不再应用后续作者重映射；主分析则保留历史作者映射。两套方案并不相同：例如，两位编码者均将From MOOCCube归为Task、将Pop-up Reflection Question归为Process，而历史作者映射将其分别归为Process和Self-Regulation；TA Answer Browser的裁决类别为Other，但历史分析管线将其归为Self-Regulation。不能通过改动工作簿中的原始评分来消除这些差异。包括其他作者决定在内的完整映射见Online Resource 1附录A.6。

The post-remapping agreement statistics in Online Resource 1, Appendix A.5, use separately derived classifications. They do not replace the raw ratings in these workbooks and do not represent a second independent coding exercise or establish construct validity.

Online Resource 1附录A.5的重映射后一致性统计量使用另外派生的分类，不替代本工作簿中的原始评分，也不代表第二次独立编码或构念效度的确立。

5. Historical instructions and feature labels 历史说明与功能标签

The reference to Coding_Manual.docx in the Instructions worksheet is the historical filename used in the coding materials. The corresponding manual is supplied in this Online Resources package as Online_Resource_1_Coding_Manual.docx. Its revision note distinguishes the original coding instructions from subsequent corrections and author-level mapping explanations. The historical Quick Reference is preserved; the clarification of overlapping category boundaries and the category-order tie-breaking rule is provided in the revision note in Online Resource 1.

Instructions工作表中的Coding_Manual.docx是编码材料使用的历史文件名。本Online Resources材料包中的对应手册名为Online_Resource_1_Coding_Manual.docx，其修订说明区分了原始编码指导与后续勘误、作者级映射解释。历史Quick Reference工作表保持原样；类别边界重叠及用于边界裁定的类别排序规则，已在Online Resource 1的修订说明中澄清。

Chinese feature labels retain the spacing shown in the original workbooks (for example, “来自 mooccube” and “来自 Faq”). The corresponding analysis tables may normalise this spacing. Such normalisation identifies the same base features and does not change the recorded classifications. The four Baike-variant interactions and their historical versus neutral mapping are documented separately in Online Resource 1, Appendix A.6; they are not four additional coding items.

中文功能标签保留原始工作簿中的空格形式（如“来自 mooccube”和“来自 Faq”）。对应分析表可能对这些空格进行标准化处理；这种处理用于识别同一基础功能，不改变原始分类。4次Baike变体交互及其在历史映射与中性映射中的分类另见Online Resource 1附录A.6；它们不是另外4个编码条目。
